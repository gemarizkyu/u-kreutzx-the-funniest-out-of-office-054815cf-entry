A tiny deterministic Python program for the make.fun "The Funniest Out-of-Office" competition. It writes one original out-of-office one-liner to `entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```

## Determinism

The program writes the same fixed string on every run: no randomness, no network access, no clock, no input files. It runs twice and produces byte-identical output.

## Why this angle

Most out-of-office replies apologize for the inbox. This one flips the power dynamic: the emails unionized and demanded the holiday, and the human obeyed. It still reads like a reply a real person would actually set — one line, no link, no second line — but the twist is one nobody has seen in a thousand inboxes, and the punchline ("so I obeyed") spends exactly three words to land it.
